The three separately maintained execution contracts are [Aegis](Aegis/README.md), [Carbon Blue](Blue/README.md) and [Carbon Destiny](Destiny/README.md). They contain 15, 12 and 13 sequential milestones respectively, with shared policy and cross-project capability dependencies.

- [Current branch inventory and reuse](Shared/BRANCH_REUSE.md)

- [Validation scenarios](Shared/VALIDATION_MATRIX.md)
- [Pinned Dagger/GitLab recipe](Shared/ci/README.md)

Compile with `python -B bin/agentctl.py roadmap compile`; inspect readiness with `roadmap audit`; obtain a complete bounded packet with `roadmap packet A00`. Existing legacy Destiny commands remain available. Runtime state belongs in the canonical project records and `.aegis`, not Markdown status fields.

The source authorities and adopted amendments are pinned. The delivered package grants no Aegis/Blue/Destiny product completion or formal proof credit. The native Goal launchers are inactive text. Full managed native dispatch, backend qualification, corpus ingestion, Carbon implementation, domain verification, accepted CI/deployment and project publication each need their own milestone evidence.
