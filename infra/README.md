# Controller runtime

Python 3.11+ standard library only. The version-one roadmap interfaces separate
profiles, policy, execution, source inventory, evidence, native observations,
knowledge and review. `roadmap_project` adapts the registered canonical record
through one existing transaction owner. Shared atomic writes, process supervision,
confinement, locks and recovery remain their existing implementations.

`python -B bin/agentctl.py roadmap profile Aegis` describes the actual record owner.
`interfaces audit` and `interfaces compare --baseline-ref COMMIT` emit source-bound
structural observations without importing the target modules or starting inference.
See [interface contracts](../Roadmaps/Shared/INTERFACES.md).

The preserved Destiny dispatcher still owns its original plans, context and receipt
lineage; `formal.py` binds its public contracts and exact verifier observations.
New roadmap command families do not reinterpret old evidence. Python/Rust proposals
cover every maintained body under their declared roots; they supply no Rust
implementation or proof credit.

`python scripts/selftest.py` exercises operational regressions. Formal control invariants
and their deductive proof entry point are in `verification/`; their scope is narrower than
Python implementation correctness and is documented there.
