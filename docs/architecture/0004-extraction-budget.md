# ADR 0004: Bound and reuse extraction observations

Status: accepted for the MetaRocq specialization, 2026-10-03.
Stakeholders: supervising engineer and implementation agents.
Concern: repeated tool execution consumes compute without changing the result;
interruptions must not erase attempt counts. The decision record uses
ISO/IEC/IEEE 42010 concerns, rationale and correspondence without claiming
standards certification.

Reuse decision: extend the existing locked MetaRocq state and atomic writer.
Do not introduce a second scheduler or generic agent framework. The target's
opam cache handles dependency build cost; this controller handles generation.

Decision: allow at most two generation attempts and reserve at most 1,200
seconds per cycle, at most 600 per attempt. Persist the full reservation before
launch. A failure retry needs a written diagnosis and a change in driver,
bootstrap recipe, source/toolchain lock, executable identity, installation
export, relevant environment or time allowance. A documentation-only edit
cannot qualify. A crash keeps its reservation and clears the previous active
observation; historical evidence remains in the ledger and files.

An intact successful observation is returned with `reused: true` after
rechecking the original sources, frozen contract, driver and output hashes.
This reuses an earlier generation observation; it does not assert that the
current installed toolchain was rerun. Modified generated bytes are rejected.

The attempt history is included in the durable PR receipt. Exhaustion requires
publishing the diagnosis and starting a new reviewed scope. This enforcement
applies to managed calls, not arbitrary processes launched outside Aegis; it
is not an OS sandbox or proof that a diagnosis is semantically correct. It
does not yet budget Kani, HOL4 or CI dependency installation.

Validation includes intact-output reuse, blind retry rejection, documentation
edits, corrected-input retry, exhausted allowance, restart after interruption,
and invalid time budgets. These are controller tests, not MetaRocq proofs.
