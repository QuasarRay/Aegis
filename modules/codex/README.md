# Host adapter policy

Use the host's named Max reasoning profile; record an unavailable exact profile.
Do not install or overwrite host configuration automatically. `config/managed.toml`
provides a reviewed preference fragment rather than selecting a different model.
At most one authorized child may be active; no nested delegation. The parent controls
canonical decisions and proof claims. Context and output budgets save cost without
reducing reasoning depth. The CLI cannot enforce a provider's model selection or billing.
